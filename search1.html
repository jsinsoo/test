탐색 알고리즘 시각화

선형 탐색 · 이진 탐색 · 해시 탐색 · DFS · BFS를 단계별로 관찰합니다.

1. 선형 탐색 Linear Search

핵심 앞에서부터 하나씩 차례대로 비교합니다. 정렬되지 않은 데이터에서도 사용할 수 있지만, 최악의 경우 모든 원소를 확인해야 합니다.
찾을 값: 속도
80
31
212
53
174
95
306
선형 탐색 준비 완료 찾을 값: 17 index 0: 8와 17 비교 index 1: 3와 17 비교 index 2: 21와 17 비교 index 3: 5와 17 비교 index 4: 17와 17 비교 성공: 17은 index 4에 있습니다. 
data = [8, 3, 21, 5, 17, 9, 30]

target = 17

for i in range(len(data)):
    if data[i] == target:
        print("찾음:", i)
        break

2. 이진 탐색 Binary Search

핵심 정렬된 데이터에서 가운데 값을 확인하고, 찾을 값이 더 작으면 왼쪽, 더 크면 오른쪽 절반만 탐색합니다.
찾을 값: 속도
20
41
72
103
154
185
236
297
318
이진 탐색 준비 완료: 데이터는 정렬되어 있습니다. 찾을 값: 23 left=0, right=8, mid=4, 가운데 값=15 15 < 23 이므로 오른쪽 절반 탐색 left=5, right=8, mid=6, 가운데 값=23 성공: 23은 index 6에 있습니다. 
data = [2, 4, 7, 10, 15, 18, 23, 29, 31]

target = 23

left = 0
right = len(data) - 1

while left <= right:
    mid = (left + right) // 2

    if data[mid] == target:
        print("찾음:", mid)
        break
    elif data[mid] < target:
        left = mid + 1
    else:
        right = mid - 1

3. 해시 탐색 Hash Search

핵심 key를 이용해 값을 바로 찾습니다. 파이썬의 딕셔너리는 해시 탐색 구조를 사용합니다.
찾을 과일:
apple1000원
banana2000원
orange1500원
melon5000원
해시 탐색 준비 완료 찾을 key: banana 성공: banana의 값은 2000원입니다. 딕셔너리는 key를 이용하여 값을 빠르게 찾습니다. 
price = {
    "apple": 1000,
    "banana": 2000,
    "orange": 1500,
    "melon": 5000
}

print(price["banana"])

4. 깊이 우선 탐색 DFS

핵심 한 방향으로 최대한 깊게 들어간 뒤, 더 이상 갈 곳이 없으면 되돌아옵니다. 재귀 또는 스택을 사용합니다.
그래프 연결 관계: A → B, C / B → D, E / C → F / E → G
시작 노드: 속도
A
B
C
D
E
F
G
DFS 준비 완료 방문: A A에서 B로 깊게 이동 방문: B B에서 D로 깊게 이동 방문: D B에서 E로 깊게 이동 방문: E E에서 G로 깊게 이동 방문: G A에서 C로 깊게 이동 방문: C C에서 F로 깊게 이동 방문: F DFS 탐색 종료 
graph = {
    "A": ["B", "C"],
    "B": ["D", "E"],
    "C": ["F"],
    "D": [],
    "E": ["G"],
    "F": [],
    "G": []
}

def dfs(node):
    print(node)
    for next_node in graph[node]:
        dfs(next_node)

dfs("A")

5. 너비 우선 탐색 BFS

핵심 가까운 노드부터 차례대로 탐색합니다. 큐를 사용하며, 최단 거리 탐색의 기본이 됩니다.
그래프 연결 관계: A → B, C / B → D, E / C → F / E → G
시작 노드: 속도
A
B
C
D
E
F
G
BFS 준비 완료 초기 큐: [A] 방문: A B를 큐에 추가 → 현재 큐: [B] C를 큐에 추가 → 현재 큐: [B, C] 방문: B D를 큐에 추가 → 현재 큐: [C, D] E를 큐에 추가 → 현재 큐: [C, D, E] 방문: C F를 큐에 추가 → 현재 큐: [D, E, F] 방문: D 방문: E G를 큐에 추가 → 현재 큐: [F, G] 방문: F 방문: G BFS 탐색 종료 
from collections import deque

graph = {
    "A": ["B", "C"],
    "B": ["D", "E"],
    "C": ["F"],
    "D": [],
    "E": ["G"],
    "F": [],
    "G": []
}

queue = deque(["A"])

while queue:
    node = queue.popleft()
    print(node)

    for next_node in graph[node]:
        queue.append(next_node)
