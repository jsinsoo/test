[12정01-01] 유무선 네트워크와 공유·협력·소통

유무선 네트워크의 특성을 이해하고, 컴퓨팅 시스템 간 공유·협력·소통을 위한 네트워크 환경을 구성한다.

OX 문항

5지선다형

파이썬 코드 서술형

서술형 1. 다음 파이썬 코드는 같은 네트워크에 있는 기기들이 공유 폴더 접근 가능 여부를 점검하는 간단한 모의 프로그램이다. 출력 결과를 쓰고, 협력적 의사소통을 위한 네트워크 구성에서 확인해야 할 요소 2가지를 서술하시오.
devices = {"교사용PC": True, "학생노트북": True, "태블릿": False} for name, shared in devices.items(): print(name, "공유가능" if shared else "공유불가")
예시 답안:
교사용PC 공유가능
학생노트북 공유가능
태블릿 공유불가
설명: 같은 네트워크 연결 여부, IP/와이파이 연결 상태, 공유 권한, 방화벽, 접근 계정 등을 확인해야 한다. 유무선 네트워크는 여러 컴퓨팅 시스템이 자료를 공유하고 협력·소통하도록 돕는 환경이다.

[12정01-02] 사물인터넷 구성과 동작 원리

사물인터넷의 구성과 동작 원리를 분석하고, 사물인터넷 기술로 인한 개인의 삶과 사회의 변화를 예측한다.

OX 문항

5지선다형

파이썬 코드 서술형

서술형 1. 다음 코드는 온도 센서 값을 바탕으로 에어컨 동작을 결정하는 IoT 시스템의 일부를 모의한 것이다. 출력 결과를 쓰고, 이 시스템의 센서·처리·동작 장치를 구분하여 설명하시오.
temperature = 31 if temperature >= 30: action = "에어컨 켜기" else: action = "대기" print("현재 온도:", temperature) print("명령:", action)
예시 답안:
현재 온도: 31
명령: 에어컨 켜기
설명: 센서는 온도 센서, 처리는 조건 판단을 수행하는 컴퓨팅 장치 또는 프로그램, 동작 장치는 에어컨/릴레이/스마트 플러그이다. IoT는 센서로 데이터를 수집하고 네트워크로 전달하며 처리 결과에 따라 장치를 제어한다.

[12정01-03] 피지컬 컴퓨팅 장치 선택과 IoT 시스템 설계

문제 해결에 적합한 피지컬 컴퓨팅 시스템 장치를 선택하여 사물인터넷 시스템을 설계한다.

OX 문항

5지선다형

파이썬 코드 서술형

서술형 1. 스마트 화분 시스템을 설계한다고 하자. 다음 코드는 토양 습도 값에 따라 물 주기 장치를 제어하는 모의 코드이다. 출력 결과를 쓰고, 필요한 피지컬 컴퓨팅 장치 3가지를 쓰시오.
soil = 25 if soil < 30: pump = "작동" else: pump = "정지" print("토양습도", soil) print("물펌프", pump)
예시 답안:
토양습도 25
물펌프 작동
필요 장치: 토양 습도 센서, 마이크로컨트롤러, 물펌프 또는 릴레이, 네트워크 모듈 등이 적합하다. 문제 해결 목적에 맞게 입력 장치, 처리 장치, 출력/구동 장치를 선택해야 한다.
