OX 1

클래스는 객체를 만들기 위한 설계도이다.

예시 코드

class Student:
    def say_hello(self):
        print('안녕하세요')

s1 = Student()
s1.say_hello()

출력 결과

안녕하세요
OX 2

같은 클래스로 만든 객체도 서로 다른 속성 값을 가질 수 있다.

예시 코드

class Car:
    def __init__(self, brand):
        self.brand = brand

c1 = Car('현대')
c2 = Car('기아')

print(c1.brand)
print(c2.brand)

출력 결과

현대
기아
OX 3

상속은 is-a 관계, 포함은 has-a 관계에 가깝다.

예시 코드

class Animal:
    pass

class Dog(Animal):
    pass

print(isinstance(Dog(), Animal))

출력 결과

True
OX 4

인스턴스 메서드의 첫 번째 매개변수 self는 객체 자신을 가리킨다.

예시 코드

class Person:
    def set_name(self, name):
        self.name = name

p = Person()
p.set_name('인수')
print(p.name)

출력 결과

인수
OX 5

부모 메서드를 자식 클래스에서 다시 정의하는 것은 오버라이딩이다.

예시 코드

class Animal:
    def sound(self):
        print('소리')

class Cat(Animal):
    def sound(self):
        print('야옹')

Cat().sound()

출력 결과

야옹

OX 8

정적 메서드는 self나 cls 없이 호출할 수 있다.

예시 코드

class MathTool:
    @staticmethod
    def add(a, b):
        return a + b

print(MathTool.add(3, 5))

출력 결과

8
OX 9

추상 클래스는 직접 객체 생성이 불가능하다.

예시 코드

from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self):
        pass

print('추상 클래스는 설계 규약 역할')

출력 결과

추상 클래스는 설계 규약 역할
OX 10

다형성은 같은 메서드 이름이 객체마다 다르게 동작하는 것이다.

예시 코드

class Dog:
    def speak(self):
        return '멍멍'

class Cat:
    def speak(self):
        return '야옹'

for animal in [Dog(), Cat()]:
    print(animal.speak())

출력 결과

멍멍
야옹

@property는 메서드를 속성처럼 접근하게 한다.

예시 코드

class Circle:
    def __init__(self, r):
        self.r = r
    @property
    def diameter(self):
        return self.r * 2

c = Circle(5)
print(c.diameter)

출력 결과

10

    def draw(self):

    shape.draw()

원을 그린다
사각형을 그린다

find는 없으면 -1을 반환하고 index는 오류가 난다.

예시 코드

s = 'python'

print(s.find('x'))
try:
    print(s.index('x'))
except ValueError:
    print('ValueError 발생')

출력 결과

-1
ValueError 발생
