[12정02-01] 디지털 데이터 압축과 효율성 평가

디지털 데이터 압축의 개념과 필요성을 이해하고, 압축의 효율성을 분석하여 평가한다.

OX 문항

5지선다형

파이썬 코드 서술형

서술형 1. 다음 파이썬 코드는 압축 전과 압축 후의 크기를 이용하여 압축률과 절감률을 계산한다. 출력 결과를 쓰고, 압축 효율성을 평가할 때 고려할 점 2가지를 서술하시오.
original = 1200 compressed = 450 ratio = compressed / original saving = (1 - ratio) * 100 print("압축률:", round(ratio, 2)) print("절감률:", round(saving, 1), "%")
예시 답안:
압축률: 0.38
절감률: 62.5 %
설명: 압축률은 압축 후 크기/압축 전 크기이므로 450/1200=0.375가 되어 반올림하면 0.38이다. 절감률은 1-0.375=0.625, 즉 62.5%이다. 압축 효율성은 용량 감소 정도, 복원 가능성, 품질 손실 여부, 압축·해제 시간 등을 함께 고려해야 한다.

[12정02-02] 암호화와 안전한 데이터 관리

암호화의 개념을 이해하고, 암호화를 활용하여 데이터를 안전하게 관리하는 사례를 비교ㆍ분석한다.

OX 문항

5지선다형

파이썬 코드 서술형

서술형 1. 다음 코드는 글자의 유니코드 값을 일정한 수만큼 이동시키는 간단한 시저 암호 모의 코드이다. 출력 결과를 쓰고, 암호화를 활용한 데이터 보호 사례를 2가지 설명하시오.
text = "ABC" key = 2 encrypted = "" for ch in text: encrypted += chr(ord(ch) + key) print(encrypted)
예시 답안:
CDE
설명: A, B, C의 문자 코드가 각각 2씩 증가하여 C, D, E가 된다. 암호화는 인터넷 뱅킹, 메신저 종단 간 암호화, 파일 암호화, 비밀번호 저장, HTTPS 통신 등에서 데이터를 안전하게 관리하는 데 활용된다. 암호화된 정보는 권한 없는 사람이 내용을 바로 이해하기 어렵게 만든다.

[12정02-03] 빅데이터 개념과 문제 해결 데이터 수집

빅데이터의 개념과 특징에 대한 이해를 바탕으로, 문제 해결에 적합한 데이터를 수집한다.

OX 문항

5지선다형

파이썬 코드 서술형

서술형 1. 다음 코드는 미세먼지 문제 해결을 위해 수집한 데이터에서 기준값 이상인 날을 찾는 예시이다. 출력 결과를 쓰고, 문제 해결에 적합한 빅데이터를 수집할 때 고려할 점 2가지를 서술하시오.
pm10 = [28, 55, 81, 43, 92] bad_days = [x for x in pm10 if x >= 80] print("나쁨 이상 일수:", len(bad_days)) print("값:", bad_days)
예시 답안:
나쁨 이상 일수: 2
값: [81, 92]
설명: 80 이상인 값은 81과 92 두 개이다. 빅데이터 수집에서는 문제 해결 목적과 관련성, 데이터의 정확성, 충분한 양, 최신성, 수집 출처의 신뢰성, 개인정보 보호와 윤리성을 고려해야 한다.

[12정02-04] 빅데이터 시각화와 의미 해석

빅데이터 분석 도구를 활용하여 데이터를 시각화하고 그 의미와 가치를 해석한다.

OX 문항

5지선다형

파이썬 코드 서술형

서술형 1. 다음 코드는 월별 이용자 수 데이터의 평균과 최대 이용자 수가 발생한 월을 구한다. 출력 결과를 쓰고, 이 데이터를 막대그래프로 시각화할 때 해석할 수 있는 의미를 서술하시오.
users = {"3월": 120, "4월": 180, "5월": 150, "6월": 210} avg = sum(users.values()) / len(users) max_month = max(users, key=users.get) print("평균:", avg) print("최대 월:", max_month, users[max_month])
예시 답안:
평균: 165.0
최대 월: 6월 210
설명: 전체 합은 660이고 4개월이므로 평균은 165.0이다. 가장 큰 값은 6월 210이다. 막대그래프로 시각화하면 월별 이용자 수의 증가·감소 추세, 최고 이용 월, 평균보다 높은 달과 낮은 달을 쉽게 비교할 수 있다. 해석 과정에서는 데이터 편향이나 개인정보 등 사회·윤리적 측면도 함께 살펴야 한다.
