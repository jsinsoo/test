OX 1

파이썬에서 문자열은 한 번 생성되면 그 내용을 직접 수정할 수 없다 (immutable).

정답 O

상세 풀이

문자열은 변경 불가능한 자료형입니다. 기존 문자열 자체를 고치는 것이 아니라, replace나 strip 같은 메서드는 새 문자열을 만들어 반환합니다.

예시 코드

s = 'python'
print(s)
print(id(s))

s = s.upper()
print(s)
print(id(s))

출력 결과

python
Python
OX 2

s = "abc"일 때, s[1] = "B"와 같이 특정 문자를 변경할 수 있다.

정답 X

상세 풀이

문자열은 불변 자료형이므로 인덱스로 특정 문자를 직접 바꿀 수 없습니다. 바꾸려면 슬라이싱이나 replace로 새 문자열을 만들어야 합니다.

예시 코드

s = 'abc'

try:
    s[1] = 'B'
except TypeError:
    print('문자열은 직접 수정 불가')

출력 결과

문자열은 직접 수정 불가
OX 3

"apple".split("p")의 결과는 ["a", "", "le"] 이다.

정답 O

상세 풀이

split은 지정한 구분자를 기준으로 문자열을 나눕니다. apple에는 p가 연속으로 두 번 나오므로 p와 p 사이의 빈 부분이 빈 문자열로 포함됩니다.

예시 코드

result = 'apple'.split('p')
print(result)

출력 결과

['a', '', 'le']
OX 4

len("안녕하세요")의 결과는 5이다.

정답 O

상세 풀이

len은 문자열의 문자 개수를 셉니다. 안녕하세요는 한글 5글자로 이루어져 있으므로 결과는 5입니다.

예시 코드

s = '안녕하세요'
print(len(s))

출력 결과

5
OX 5

" python ".strip()은 원본 문자열 자체를 변경한다.

정답 X

상세 풀이

strip은 양쪽 공백을 제거한 새 문자열을 반환합니다. 원본 문자열은 그대로이며, 결과를 사용하려면 변수에 다시 저장해야 합니다.

예시 코드

s = ' python '
t = s.strip()

print('원본:', repr(s))
print('결과:', repr(t))

출력 결과

원본: ' python '
결과: 'python'
OX 6

s.find("a")는 문자열 s에 "a"가 없으면 -1을 반환한다.

정답 O

상세 풀이

find는 찾는 문자열이 없을 때 오류를 내지 않고 -1을 반환합니다. 그래서 존재 여부를 안전하게 확인할 때 사용할 수 있습니다.

예시 코드

s = 'python'
print(s.find('a'))

출력 결과

-1
OX 7

s.index("a")는 문자열 s에 "a"가 없으면 -1을 반환한다.

정답 X

상세 풀이

index는 찾는 문자열이 없으면 -1이 아니라 ValueError를 발생시킵니다. find와 index의 중요한 차이입니다.

예시 코드

s = 'python'

try:
    print(s.index('a'))
except ValueError:
    print('ValueError 발생')

출력 결과

ValueError 발생
OX 8

"1,2,3".split() 코드의 결과는 ["1", "2", "3"]이다.

정답 X

상세 풀이

split()에 구분자를 지정하지 않으면 공백을 기준으로 나눕니다. 문자열에 공백이 없으므로 전체 문자열이 하나의 원소가 됩니다.

예시 코드

s = '1,2,3'
print(s.split())
print(s.split(','))

출력 결과

['1,2,3']
['1', '2', '3']
OX 9

"*".join(["a", "b", "c"])의 결과는 "*a*b*c"이다.

정답 X

상세 풀이

join은 구분자를 각 요소 사이에 넣습니다. 맨 앞에는 붙지 않으므로 결과는 a*b*c입니다.

예시 코드

result = '*'.join(['a', 'b', 'c'])
print(result)

출력 결과

a*b*c

다음 중 문자열 양쪽의 공백을 제거하는 메소드는?

정답 .strip()

상세 풀이

strip은 문자열의 왼쪽과 오른쪽 끝에 있는 공백을 제거합니다. 왼쪽만 제거하려면 lstrip, 오른쪽만 제거하려면 rstrip을 사용합니다.

예시 코드

s = '  python  '
print(repr(s.strip()))
print(repr(s.lstrip()))
print(repr(s.rstrip()))

출력 결과

'python'
'python  '
'  python'

s.find("x")와 s.index("x")의 가장 큰 차이점은?

정답 찾는 값이 없을 때 find는 -1을, index는 오류를 발생시킨다

상세 풀이

find는 찾는 값이 없으면 -1을 반환하고, index는 ValueError를 발생시킵니다. 프로그램 흐름을 안전하게 처리하려면 이 차이를 알아야 합니다.

예시 코드

s = 'python'
print(s.find('x'))

try:
    print(s.index('x'))
except ValueError:
    print('index는 오류 발생')

출력 결과

-1
index는 오류 발생
