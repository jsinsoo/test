1. 파이썬 예제 코드: Pandas 데이터 분석

1.1. 기초 파이썬 예시 코드 (5개)

Pandas의 핵심 자료구조인 Series와 DataFrame을 만들고 데이터를 선택하는 방법을 익힙니다.

1. Series 생성하기

# 1차원 데이터 구조인 Series를 생성합니다.

import pandas as pd

s = pd.Series([10, 20, 30, 40], index=['a', 'b', 'c', 'd'])

print("--- Pandas Series ---")
print(s)
print("\n인덱스 'c'의 값:", s['c'])
출력 결과
--- Pandas Series --- a 10 b 20 c 30 d 40 dtype: int64 인덱스 'c'의 값: 30
상세 설명
pd.Series()는 1차원 데이터를 만드는 명령입니다. index를 지정하면 기본 숫자 인덱스 대신 a, b, c, d처럼 이름표를 붙일 수 있습니다. s['c']는 인덱스가 c인 값 30을 선택합니다.

2. DataFrame 생성하기

# 2차원 데이터 구조인 DataFrame을 생성합니다. (엑셀 시트와 유사)

import pandas as pd

data = {
    '이름': ['인수샘', '홍길동', '구운몽'],
    '나이': [30, 25, 28],
    '도시': ['서울', '부산', '광주']
}

df = pd.DataFrame(data)
print("--- Pandas DataFrame ---")
print(df)
출력 결과
--- Pandas DataFrame --- 이름 나이 도시 0 인수샘 30 서울 1 홍길동 25 부산 2 구운몽 28 광주
상세 설명
딕셔너리의 key는 열 이름이 되고, value 리스트는 각 열의 데이터가 됩니다. pd.DataFrame(data)는 엑셀 표처럼 행과 열이 있는 2차원 데이터 구조를 만듭니다.

3. 특정 열(Column) 선택하기

# 열 이름을 사용하여 데이터를 추출합니다.
names = df['이름']
print("이름 열만 추출:")
print(names)

# 여러 열 선택
subset = df[['이름', '도시']]
print("\n이름과 도시 열 추출:")
print(subset)
출력 결과
이름 열만 추출: 0 인수샘 1 홍길동 2 구운몽 Name: 이름, dtype: object 이름과 도시 열 추출: 이름 도시 0 인수샘 서울 1 홍길동 부산 2 구운몽 광주
상세 설명
df['이름']처럼 열 이름 하나를 넣으면 Series 형태로 한 열만 가져옵니다. df[['이름', '도시']]처럼 열 이름 리스트를 넣으면 여러 열을 DataFrame 형태로 가져옵니다.

4. 조건에 맞는 행 필터링

# 나이가 27세 이상인 데이터만 필터링합니다.

older_than_27 = df[df['나이'] >= 27]
print("27세 이상인 사람:")
print(older_than_27)
출력 결과
27세 이상인 사람: 이름 나이 도시 0 인수샘 30 서울 2 구운몽 28 광주
상세 설명
df['나이'] >= 27은 각 행이 조건을 만족하는지 True/False로 판단합니다. 이 조건식을 df[...] 안에 넣으면 True인 행만 남습니다.

5. 데이터 요약 통계 확인

# describe() 함수로 수치형 데이터의 통계 정보를 한눈에 확인합니다.

print("데이터 요약 정보:")
print(df.describe())
출력 결과
데이터 요약 정보: 나이 count 3.000000 mean 27.666667 std 2.516611 min 25.000000 25% 26.500000 50% 28.000000 75% 29.000000 max 30.000000
상세 설명
describe()는 숫자형 열의 개수, 평균, 표준편차, 최솟값, 사분위수, 최댓값을 자동으로 계산합니다. 데이터의 전체적인 분포를 빠르게 확인할 때 유용합니다.

1.2. 응용 파이썬 예시 코드 (5개)

데이터 정제, 결합, 그룹화 등 실질적인 데이터 가공 기법을 다룹니다.

1. 새로운 열 추가 및 계산

# 기존 데이터를 바탕으로 새로운 열을 생성합니다.
df['내년나이'] = df['나이'] + 1
print(df)
출력 결과
이름 나이 도시 내년나이 0 인수샘 30 서울 31 1 홍길동 25 부산 26 2 구운몽 28 광주 29
상세 설명
df['내년나이'] = df['나이'] + 1은 기존 나이 열에 1을 더한 결과를 새 열로 저장합니다. Pandas는 열 전체에 같은 계산을 한 번에 적용할 수 있습니다.

2. 결측치(NaN) 처리하기

# 비어있는 데이터를 찾거나 채워 넣습니다.

import numpy as np

df.loc[1, '도시'] = np.nan # 홍길동의 도시를 결측치로 변경
print("--- 결측치 발생 ---")
print(df)

# 결측치를 '알 수 없음'으로 채우기
df_filled = df.fillna('알 수 없음')
print("\n--- 결측치 채우기 결과 ---")
print(df_filled)
출력 결과
--- 결측치 발생 --- 이름 나이 도시 내년나이 0 인수샘 30 서울 31 1 홍길동 25 NaN 26 2 구운몽 28 광주 29 --- 결측치 채우기 결과 --- 이름 나이 도시 내년나이 0 인수샘 30 서울 31 1 홍길동 25 알 수 없음 26 2 구운몽 28 광주 29
상세 설명
np.nan은 값이 비어 있음을 뜻하는 결측치입니다. fillna('알 수 없음')은 비어 있는 값을 지정한 문자열로 채운 새 DataFrame을 만듭니다.

3. 데이터 그룹화 및 집계 (groupby)

# 특정 기준별로 데이터를 묶어 평균이나 합계를 구합니다.

data = {
    '부서': ['개발', '기획', '개발', '기획', '인사'],
    '급여': [5000, 4000, 5500, 4200, 3800]
}
emp_df = pd.DataFrame(data)

dept_avg = emp_df.groupby('부서')['급여'].mean()
print("부서별 평균 급여:")
print(dept_avg)
출력 결과
부서별 평균 급여: 부서 개발 5250.0 기획 4100.0 인사 3800.0 Name: 급여, dtype: float64
상세 설명
groupby('부서')는 같은 부서끼리 데이터를 묶습니다. 그 뒤 ['급여'].mean()을 사용하면 부서별 급여 평균을 계산할 수 있습니다.

4. 데이터 합치기 (merge)

# SQL의 Join과 유사하게 공통 열을 기준으로 합칩니다.

df1 = pd.DataFrame({'이름': ['인수샘', '홍길동'], '성적': [90, 80]})
df2 = pd.DataFrame({'이름': ['인수샘', '홍길동'], '출석': [100, 95]})

merged = pd.merge(df1, df2, on='이름')
print("데이터 병합 결과:")
print(merged)
출력 결과
데이터 병합 결과: 이름 성적 출석 0 인수샘 90 100 1 홍길동 80 95
상세 설명
pd.merge(df1, df2, on='이름')은 두 DataFrame에서 이름 열이 같은 행끼리 연결합니다. 학생 정보, 성적, 출석처럼 나뉜 표를 하나로 합칠 때 사용합니다.

5. CSV 파일 읽기 및 저장

# 데이터프레임을 CSV 파일로 저장
df.to_csv('my_data.csv', index=False, encoding='utf-8-sig')

# CSV 파일 불러오기
new_df = pd.read_csv('my_data.csv')
print("불러온 데이터:")
print(new_df.head())
출력 결과
불러온 데이터: 이름 나이 도시 내년나이 0 인수샘 30 서울 31 1 홍길동 25 NaN 26 2 구운몽 28 광주 29
상세 설명
to_csv()는 DataFrame을 CSV 파일로 저장합니다. index=False는 행 번호를 파일에 저장하지 않겠다는 뜻이고, utf-8-sig는 엑셀에서 한글이 깨지지 않도록 도와줍니다. read_csv()는 CSV 파일을 다시 DataFrame으로 불러옵니다.

1.3. 심화 파이썬 예시 코드 (4개)

고급 데이터 변형 및 분석 기법입니다.

1. 데이터 재구조화 (Pivot Table)

# 복잡한 데이터를 요약하여 표 형태로 재구성합니다.

data = {
    '날짜': ['1일', '1일', '2일', '2일'],
    '도시': ['서울', '부산', '서울', '부산'],
    '온도': [25, 28, 26, 29]
}
df = pd.DataFrame(data)

# '도시'를 행으로, '날짜'를 열로 하여 '온도' 값을 보여주는 피벗 테이블
pivot = df.pivot_table(index='도시', columns='날짜', values='온도')
print("피벗 테이블 결과:")
print(pivot)
출력 결과
피벗 테이블 결과: 날짜 1일 2일 도시 부산 28 29 서울 25 26
상세 설명
pivot_table()은 데이터를 요약 표 형태로 재구성합니다. 여기서는 도시를 행, 날짜를 열, 온도를 값으로 사용하여 도시별·날짜별 온도를 한눈에 비교합니다.

2. 함수 적용하기 (.apply())

# 행이나 열 단위로 복잡한 계산을 일괄 적용합니다.

df = pd.DataFrame({'점수1': [80, 90, 70], '점수2': [85, 95, 75]})

# 최댓값을 구하는 함수 적용
df['최고점수'] = df.apply(lambda row: max(row['점수1'], row['점수2']), axis=1)

# 평균 구하기
df['평균점수'] = df.apply(lambda row: (row['점수1'] + row['점수2']) / 2, axis=1)
print(df)
출력 결과
점수1 점수2 최고점수 평균점수 0 80 85 85 82.5 1 90 95 95 92.5 2 70 75 75 72.5
상세 설명
apply()는 각 행이나 열에 함수를 적용합니다. axis=1은 행 단위 계산을 의미합니다. lambda row를 사용해 한 학생의 점수1, 점수2를 비교하거나 평균을 계산합니다.

3. 고유값 확인 및 빈도수 세기

survey = pd.Series(['좋음', '보통', '좋음', '나쁨', '좋음', '보통'])

print("고유값 종류:", survey.unique())
print("\n값별 빈도수:")
print(survey.value_counts())
출력 결과
고유값 종류: ['좋음' '보통' '나쁨'] 값별 빈도수: 좋음 3 보통 2 나쁨 1 Name: count, dtype: int64
상세 설명
unique()는 중복을 제거하고 어떤 값들이 있는지 보여줍니다. value_counts()는 각 값이 몇 번 등장하는지 세어 설문 응답이나 범주형 데이터 분석에 자주 사용됩니다.

4. 인덱스 초기화 및 정렬

df = pd.DataFrame({'점수': [70, 95, 80]}, index=['다', '가', '나'])

# 인덱스 기준 정렬
print("인덱스 정렬:")
print(df.sort_index())

# 값 기준 정렬
print("\n점수 기준 내림차순 정렬:")
print(df.sort_values(by='점수', ascending=False))
출력 결과
인덱스 정렬: 점수 가 95 나 80 다 70 점수 기준 내림차순 정렬: 점수 가 95 나 80 다 70
상세 설명
sort_index()는 행 인덱스를 기준으로 정렬합니다. sort_values(by='점수', ascending=False)는 점수 값을 기준으로 큰 값부터 작은 값 순서로 정렬합니다.
