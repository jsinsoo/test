[12정04-01] 지능 에이전트의 개념과 특성, 인간과 인공지능의 관계

핵심: 지능 에이전트는 환경을 인식하고 판단하여 목표 달성을 위한 행동을 수행한다. 다양한 AI 제품·서비스에서 역할을 탐색하고 인간과 AI의 협력 관계를 올바르게 이해한다.

A개념과 특성을 명확히 설명하고 다양한 제품·서비스에서 역할을 탐색하여 인간과 AI의 관계를 올바르게 인식한다.
C개념과 특성을 설명하고 제품·서비스에서 역할을 탐색하여 관계를 인식한다.
E지능 에이전트의 개념을 인지하고 역할을 부분적으로 탐색한다.

1. 지능 에이전트는 환경을 인식하고 목표에 맞게 행동을 선택할 수 있다.

정답: X. 지능 에이전트의 핵심은 인식·판단·행동이지 인간의 감정 보유가 아니다.
3. 추천 시스템, 챗봇, 자율주행 시스템은 지능 에이전트의 역할을 탐색하기 좋은 사례이다.
정답: O. 이들은 데이터를 인식하고 사용자나 환경에 맞는 행동 또는 출력을 제공한다.
4. 인간과 인공지능의 관계는 경쟁만으로 설명하는 것이 가장 바람직하다.
정답: X. 인간과 AI는 협력, 보완, 책임 있는 활용의 관계로 이해해야 한다.
5. 지능 에이전트의 역할을 분석할 때 입력, 처리, 출력, 피드백을 살펴볼 수 있다.
정답: O. 에이전트 분석은 환경 인식, 판단 과정, 행동 결과, 피드백 개선 구조를 살펴보면 좋다.

파이썬 코드 서술형 1개

8. 다음 코드는 간단한 지능 에이전트의 행동 선택 예시이다. 출력 결과를 쓰시오.
class Agent:
    def act(self, battery, obstacle):
        if battery < 20:
            return "충전소로 이동"
        if obstacle:
            return "우회 경로 선택"
        return "목표 지점으로 이동"

robot = Agent()
print(robot.act(15, False))
print(robot.act(80, True))
정답: 충전소로 이동 / 우회 경로 선택. 첫 호출은 battery가 20보다 작아 충전소로 이동을 반환한다. 두 번째 호출은 배터리가 충분하지만 obstacle이 True이므로 우회 경로 선택을 반환한다.

[12정04-02] 기계학습의 개념, 지도학습과 비지도학습 비교·분석

핵심: 기계학습은 데이터에서 규칙이나 패턴을 학습하는 방법이다. 지도학습은 정답 라벨이 있는 데이터, 비지도학습은 정답 라벨 없이 구조·군집·패턴을 찾는 방식이다.

OX 문항 5개

9. 기계학습은 데이터를 이용해 패턴이나 규칙을 학습하는 기술이다.
정답: O. 기계학습은 명시적으로 모든 규칙을 코딩하지 않고 데이터에서 규칙을 학습한다.
10. 지도학습은 일반적으로 입력 데이터와 정답 라벨을 함께 사용한다.
정답: O. 예를 들어 사진과 ‘고양이/강아지’ 정답 라벨을 함께 학습한다.
11. 비지도학습은 정답 라벨 없이 데이터의 구조나 군집을 찾는 데 활용될 수 있다.
정답: O. 고객 군집화, 문서 주제 묶기 등에서 비지도학습을 사용할 수 있다.
12. 지도학습과 비지도학습은 사용하는 데이터의 정답 라벨 유무에서 차이가 난다.
정답: O. 지도학습은 라벨이 있고, 비지도학습은 라벨 없이 패턴을 찾는다.
13. 비지도학습은 항상 분류 문제의 정답을 직접 예측하는 데만 사용된다.
정답: X. 분류는 주로 지도학습이며, 비지도학습은 군집화·차원 축소·패턴 탐색 등에 쓰인다.

5지선다형 2개

14. 다음 중 지도학습 사례로 가장 적절한 것은?
정답: B. ‘스팸/정상’ 정답 라벨이 있는 데이터로 예측 모델을 학습하기 때문이다.
15. 비지도학습을 설명한 것으로 가장 적절한 것은?
정답: A. 비지도학습은 군집화처럼 라벨 없는 데이터의 구조를 발견하는 데 활용된다.

파이썬 코드 서술형 1개

16. 다음 코드는 학습 유형을 판별한다. 출력 결과를 쓰시오.
def learning_type(has_label, goal):
    if has_label and goal == "predict":
        return "지도학습"
    if not has_label and goal == "group":
        return "비지도학습"
    return "추가 분석 필요"

print(learning_type(True, "predict"))
print(learning_type(False, "group"))
정답: 지도학습 / 비지도학습. 라벨이 있고 예측이 목표이면 지도학습, 라벨 없이 묶기가 목표이면 비지도학습이다.

[12정04-03] 기계학습 적용 가능 문제 구분과 사회문제 해결

핵심: 기계학습은 데이터가 충분하고 패턴을 학습할 수 있는 문제에 적합하다. 데이터가 없거나 명확한 규칙만으로 충분한 문제, 윤리적으로 부적절한 문제에는 신중해야 한다.

OX 문항 5개

17. 기계학습은 충분한 데이터와 학습 가능한 패턴이 있는 문제에 적용하기 좋다.
정답: O. 데이터와 패턴이 있어야 모델이 의미 있는 예측이나 분류를 할 수 있다.
18. 모든 사회문제는 기계학습만 적용하면 자동으로 완전히 해결된다.
정답: X. 사회문제는 제도, 윤리, 사람의 판단, 데이터 편향 등의 요소를 함께 고려해야 한다.
19. 교통량 예측, 감염병 확산 분석, 에너지 사용량 예측은 기계학습 적용 후보가 될 수 있다.
정답: O. 과거 데이터와 패턴을 활용하여 예측 또는 분류를 수행할 수 있다.
20. 개인정보 침해 가능성이 있는 데이터는 기계학습에 사용할 때 보호와 윤리 검토가 필요하다.
정답: O. 데이터 수집·사용 목적, 익명화, 동의, 편향, 공정성 등을 점검해야 한다.
21. 단순히 두 수를 더하는 문제는 기계학습보다 규칙 기반 프로그램이 더 적합할 수 있다.
정답: O. 명확한 수식이나 규칙으로 해결되는 문제는 기계학습이 필요하지 않을 수 있다.

5지선다형 2개

22. 다음 중 기계학습 적용이 가장 적절한 문제는?
정답: B. 과거 데이터에서 패턴을 학습하여 예측할 수 있으므로 기계학습 적용 후보가 된다.
23. 기계학습으로 사회문제를 해결할 때 가장 먼저 고려해야 할 태도로 적절한 것은?
정답: B. 사회문제 해결에는 기술적 성능뿐 아니라 공정성, 윤리, 데이터 품질, 현장 적용성이 중요하다.

파이썬 코드 서술형 1개

24. 다음 코드는 기계학습 적용 가능성을 간단히 판단한다. 출력 결과를 쓰시오.
def can_use_ml(data_count, has_pattern, ethical_risk):
    if ethical_risk:
        return "윤리 검토 필요"
    if data_count >= 100 and has_pattern:
        return "기계학습 적용 가능"
    return "규칙 기반 또는 추가 데이터 필요"

print(can_use_ml(500, True, False))
print(can_use_ml(50, True, False))
print(can_use_ml(1000, True, True))
정답: 기계학습 적용 가능 / 규칙 기반 또는 추가 데이터 필요 / 윤리 검토 필요. 윤리 위험이 있으면 먼저 윤리 검토가 필요하고, 데이터가 충분하며 패턴이 있으면 적용 가능하다.
