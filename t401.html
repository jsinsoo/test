CONCEPTS

💡 핵심 개념 정리

1. 지능 에이전트

지능 에이전트는 환경을 인지하고, 인지 결과를 바탕으로 판단하며, 목표를 달성하기 위해 행동하는 컴퓨팅 개체입니다.

2. PEAS 프레임워크

P · Performance

성능 척도: 얼마나 잘했는가?

E · Environment

환경: 어디에서 활동하는가?

A · Actuators

액추에이터: 무엇으로 행동하는가?

S · Sensors

센서: 무엇으로 인지하는가?

3. 에이전트 종류

종류판단 방식예시
단순 반사 에이전트현재 입력에만 반응먼지 감지 → 흡입
모델 기반 에이전트현재 입력 + 내부 상태 고려청소한 구역 수 기억
목표 기반 에이전트목표 달성 여부 고려모든 먼지 제거
효용 기반 에이전트효율·위험·만족도를 비교청소와 충전 중 더 유리한 선택

CORE EXAMPLE

🐍 핵심 예제 코드

class SimpleAgent:
    def perceive(self, environment):
        if environment["dirty"]:
            return "dirty"
        return "clean"

    def act(self, percept):
        if percept == "dirty":
            return "suck"
        return "move"

agent = SimpleAgent()
env = {"dirty": True}

p = agent.perceive(env)
a = agent.act(p)

print("인지:", p)
print("행동:", a)
