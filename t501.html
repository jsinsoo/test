OPENING

🚀 수업 시작 멘트

스티브 잡스는 “미래를 내다보며 점들을 연결할 수는 없습니다. 오직 과거를 돌아볼 때만 그것들을 연결할 수 있죠.”라고 말했습니다. 오늘 우리는 수학, 과학, 정보라는 점들이 미래의 진로와 어떻게 연결될 수 있는지 탐색합니다. 핵심 질문은 “나의 전공 지식과 디지털 기술을 결합하면 어떤 새로운 가능성이 생길까?”입니다.

OBJECTIVES

🌱 태도적 목표

CONCEPTS

💡 핵심 개념 정리

1. 디지털 전환 DX

디지털 전환은 단순한 도구 교체가 아니라, 디지털 기술을 활용하여 산업의 전략, 문화, 업무 방식, 비즈니스 모델을 근본적으로 바꾸는 과정입니다.

2. 융합과 T자형 인재

융합

서로 다른 학문과 기술이 결합해 새로운 가치를 만드는 현상입니다.

생물정보학

생명과학 + 정보과학. 유전체 데이터를 분석해 질병과 신약 개발에 활용합니다.

T자형 인재

깊은 전공 전문성 I와 넓은 IT 활용 능력 ㅡ를 함께 갖춘 인재입니다.

평생 학습

빠르게 변하는 기술 환경에서 계속 배우고 다시 배우는 태도입니다.

CORE EXAMPLE

🐍 핵심 예제 코드

import pandas as pd

data = {
    "job": ["데이터 과학자", "AI 전문가", "생물정보학자"],
    "major": ["통계/컴공", "컴공/수학", "생명과학/컴공"],
    "salary": [12000, 15000, 11000]
}

df = pd.DataFrame(data)
cs_jobs = df[df["major"].str.contains("컴공")]

print(df)
print("--- 컴공 역량이 필요한 직업 ---")
print(cs_jobs[["job", "salary"]])
